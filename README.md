# LinkPrice 아산 신규 개원 치과 온라인 광고 제안서

GitHub Pages 배포용 정적 제안서입니다.

## /(root) 업로드 파일
- `index.html`
- `linkprice-logo.png`

두 파일을 저장소의 **root**에 업로드하면 됩니다.

## GitHub Pages 배포
1. GitHub 저장소 → **Settings**
2. **Pages** 메뉴 선택
3. **Build and deployment → Deploy from a branch**
4. Branch: `main` / Folder: `/ (root)`
5. Save
6. 잠시 후 생성된 Pages URL로 제안서를 확인합니다.

## 조작
- 오른쪽 화살표 버튼: 다음 페이지
- 왼쪽 화살표 버튼: 이전 페이지
- 키보드 `← / →`, `PageUp / PageDown`, `Home / End`
- 마우스 휠
- 모바일 스와이프

※ 제안서 내 수치형 레퍼런스/예산은 실제 집행 전 협의 및 검증을 전제로 한 제안용 구성입니다.
