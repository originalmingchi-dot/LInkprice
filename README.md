# LinkPrice | 아산 신규 개원 치과 온라인 광고 운영 제안서

GitHub Pages에서 바로 배포할 수 있는 단일 페이지형 가로 슬라이드 제안서입니다.

## Root 업로드
저장소 최상단 `/(root)`에 아래 두 파일을 업로드하세요.

- `index.html`
- `linkprice-logo.png`

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)` → Save

## 조작
- `← / →` 버튼
- 키보드 방향키 / PageUp / PageDown / Home / End
- 마우스 휠
- 모바일 좌우 스와이프

## 수정 포인트
- 광고주명/병원명은 표지의 제목과 본문에서 직접 수정할 수 있습니다.
- 예산은 `index.html`의 17페이지에서 수정할 수 있습니다.
- 사례 페이지의 수치는 실제 보유 레퍼런스가 있다면 교체해 사용하는 것을 권장합니다.
